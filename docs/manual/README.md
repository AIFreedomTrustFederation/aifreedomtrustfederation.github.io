# aifreedomtrustfederation.github.io UNIX Manual Manual

This directory contains the UNIX-style manual source for this repository.

Manual source belongs to this repo. PDF and publication builds belong to BookSmith.

**Manual coverage and publication boundary:** The [manual manifest](../../.aift/manual.json) enumerates `man0` through `man9` and marks `manualSource` as `ready`, but authored manual pages currently exist only under [`man0`](source/man0/00-introduction.md) and [`man7`](source/man7/). The other categories are indexed placeholders, not completed manual sections. The same manifest marks `pdfBuild` and `webPublish` as `planned`; these source files do not establish a completed PDF build or authorized web publication.
